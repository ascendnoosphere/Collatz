# Saturated inverse-odd-then-even join

Let \(a\) and \(b\) be integers with \(a\ge 1\) and \(b\ge 1\), and let \(u\) be an odd integer. Set \(z=2^{a}3^{b}u-1\), and assume
\[
z\equiv 2^{a}-1\pmod{2^{a+2}}.
\]
Write \(I(y)=(2y-1)/3\) and \(H(y)=(y+1)/2-1\). Then \(3\) divides \(2z-1\), the iterate \(I^{b}(z)\) equals \(2^{a+b}u-1\), and
\[
H\bigl(I^{b}(z)\bigr)=2^{a+b-1}u-1.
\]
The same hypotheses give \(u\equiv(-1)^{b}\pmod{4}\), and \(2^{a+b}\) does not divide \(2^{a+b-1}u\).

The congruence is part of the hypothesis. The statement is not claimed for an arbitrary odd integer. Nothing here asserts that the classical Collatz map sends every positive integer to \(1\).
